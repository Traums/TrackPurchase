# Участие в TrackPurchase

Общаться в issues и PR можно на русском и английском.

Для ошибки укажите версию приложения и Windows, шаги, ожидаемый и фактический результат. Для идеи опишите задачу пользователя. Удаляйте личные данные со скриншотов.

## Изменения кода

1. Обсудите крупное изменение в issue.
2. Создайте ветку от main и внесите небольшое законченное изменение.
3. Следуйте стилю окружающего кода; сохраняйте совместимость файлов данных.
4. Выполните `cargo test --locked` и `cargo build --release --locked` на Windows.
5. Обновите документацию, для UI приложите скриншоты.
6. Откройте PR с описанием задачи, результата и проверок.

# Руководство пользователя

[← На главную](../README.md)

## Создание и редактирование

Нажмите «+ Новая подписка» или Ctrl+N. Заполните название, сумму, валюту, период и дату следующего списания в формате ДД.ММ.ГГГГ. Выберите категорию, при желании добавьте свою, задайте цвет значка и заметку. Нажмите на существующую строку для редактирования.

Переключатель «Активна» в форме позволяет поставить любую подписку на паузу. Для подписок с оплатой с карты также есть кнопка при наведении на строку. Приостановленные подписки доступны через фильтр «Пауза» и не входят в итог активных расходов.

## Карта и баланс

«С карты» означает обычную регулярную подписку: реквизиты карты не запрашиваются.

«С баланса» означает отдельный остаток внутри конкретного сервиса, в валюте подписки. При нехватке средств появится предупреждение. Кнопка «Пополнить» в строке или боковой панели увеличивает записанный остаток; она не переводит реальные деньги.

## Поиск и календарь

Поиск и фильтры помогают найти сервис по категории и статусу. Сортировка поддерживает дату, сумму и название. Календарь показывает текущий месяц: точки отмечают дни списаний, цветом выделен сегодняшний день.

## Расчёты и ограничения

- Итоги приводят стоимость активных подписок к месячному и годовому эквиваленту.
- RUB, USD и EUR пересчитываются в базовую валюту по курсам из настроек; курсы обновляются вручную.
- При обработке прошедших периодов приложение продвигает даты платежей; для оплаты с баланса учитывает остаток сервиса. Это расчётная модель, а не проверка оплаты в банке.
- Даты на конец месяца учитывают длину месяца и високосные годы.
- Нет банковской синхронизации, облачного аккаунта или фонового сервиса уведомлений.

## Настройки и перенос данных

В настройках доступны тема, базовая валюта, курсы и экспорт / импорт.

Папка Windows: `%APPDATA%\TrackPurchase`.

- `subscriptions.json` — подписки.
- `settings.json` — тема, валюта, курсы и свои категории.
- `export.json`, `export.csv` — результаты экспорта подписок.

Для импорта укажите полный путь к JSON или CSV и нажмите «Импорт». Импорт объединяет записи с существующим списком; настройки не восстанавливаются. Проще использовать файл, ранее экспортированный приложением.

Для полного переноса закройте приложение и скопируйте всю папку данных на другой компьютер. Перед импортом или ручным редактированием сохраните копию этой папки. При повреждении файла приложение пытается сохранить его копию и показывает предупреждение.

## Обновление и удаление

Закройте приложение и замените исполняемый файл новой версией. Данные находятся отдельно. Для удаления приложения удалите распакованные файлы; папку данных удаляйте отдельно, только если она больше не нужна.

## Если приложение не запускается

Проверьте, что распаковали архив и используете Windows x64. Если Windows сообщает об отсутствии компонента Visual C++, установите официальный [Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). Если проблема остаётся, создайте issue с версией Windows, приложения и текстом ошибки. Не прикладывайте личные файлы подписок.

# TrackPurchase v0.1.0

Первый выпуск локального приложения для учёта подписок на Windows x64.

## Что внутри

- Обзор месячных и годовых расходов, календарь и категории.
- Поиск, сортировка, фильтры и приостановка подписок.
- Отдельные балансы сервисов, предупреждения и ручное пополнение.
- RUB, USD и EUR с курсами из настроек.
- Светлая и тёмная темы, быстрые действия при наведении.
- Локальное хранение, импорт и экспорт JSON / CSV.

## Установка

Скачайте **TrackPurchase-v0.1.0-windows-x64.zip**, распакуйте и запустите **trackpurchase.exe**. Установщик не требуется. Приложение не подписано цифровым сертификатом.

В **SHA256SUMS.txt** опубликована SHA-256 сумма архива. Сравнить её можно в PowerShell:

```powershell
Get-FileHash .\TrackPurchase-v0.1.0-windows-x64.zip -Algorithm SHA256
```

## Данные и ограничения

Данные хранятся в **%APPDATA%\TrackPurchase**. Перед обновлением сохраните копию папки. Приложение не подключается к банкам, не выполняет реальные платежи и не загружает курсы. Итоги — расчётные эквиваленты стоимости подписок. Linux и macOS не проверены.

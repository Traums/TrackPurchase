# История изменений

## [0.1.0] — 2026-11-01

Первый опубликованный выпуск для Windows x64.

### Возможности

- Подписки с недельным, месячным, квартальным и годовым периодом.
- Месячные и годовые расходы, категории, календарь списаний.
- RUB, USD, EUR с ручными курсами.
- Отдельные балансы, пополнение и предупреждения о нехватке средств.
- Поиск, фильтры, сортировка, пауза и отмена последнего удаления.
- Локальное хранение, JSON / CSV импорт и экспорт.

### Интерфейс

- Светлая и тёмная темы с акцентом на ежемесячных расходах.
- Быстрые действия при наведении, центрированные даты календаря.
- Выровненные полосы расходов по категориям.
